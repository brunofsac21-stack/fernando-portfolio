# Fernando Gregório — Portfólio

Portfólio digital pessoal, construído como uma página única (SPA) em HTML/CSS/JS puro, seguindo um sistema de design próprio ("Void").

## Seções
- **Sobre** — apresentação profissional
- **Projetos** — soluções desenvolvidas, com destaque para o WMS 3D (visualização de ocupação de armazém em Three.js)
- **Certificados** — formação e certificações

## Stack
- HTML/CSS/JS vanilla (sem build step)
- Three.js (robô 3D de transição entre seções)
- Deploy: Vercel (conectado via GitHub)

## Demos
As demos interativas dos projetos ficam em `/demos` e são servidas pelo próprio Vercel:
- `/demos/wms3d.html` — WMS 3D
- `/demos/dpa-etiquetas.html` — DPA · Etiquetas
- `/demos/ativos.html` — Controle de Ativos
